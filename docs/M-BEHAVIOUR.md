# M behaviour — reconstructed specification

This is emmm's working specification of how M behaves. It is written in our own words.
Confidence tags:

* **[DOC]** documented in the M 2.7 manual (S1) or Zicarelli 1987 (S2) — see PROVENANCE.
* **[OBS]** observed by running the original software (none yet — no emulator session so far).
* **[INF]** inferred: strongly suggested but not stated outright.
* **[UNK]** unknown; emmm's choice is noted and isolated in code (search the code for the
  tag `@m-uncertain`).

Section numbers are referenced from code comments as `M-BEHAVIOUR §n`.

---

## §1 The model in one paragraph

M is not a sequencer. It holds **four Patterns** of pitch material (notes, chords and rests,
*with no timing or duration*) and turns each into a **Voice** by running it through a fixed
chain of transformations called **Variables** [DOC]. Every Variable has **six Positions**
(Sound Choice has sixteen) [DOC]; each Position stores settings for all four Voices; exactly
one Position per Variable is active. The musician performs by switching Positions (directly,
by conducting, with Snapshots, from a MIDI keyboard) and by editing Positions while the music
runs. Every change is heard at the next event [DOC, S2: the UI and the interrupt routine
share the same global data].

```
Pattern (step list + scrambled list)
   │  Note Order: Original / Cyclic Random / Utterly Random (percent mix)
   ▼
step = note | chord | rest
   │  Note Density (probability of sounding)
   │  Accent level 0 ⇒ silent
   │  Transposition (+ keyboard transpose)
   │  Velocity = Velocity Range × Accent level (+ continuous-conducting offset)
   │  Orchestration: Voice → any set of 16 M Output Channels
   ▼
note-on ……… note-off  (duration = interval × Legato %)
   ▲
   interval to next event = Time Base ticks × Rhythm value(level), warped by Time Distortion,
   offset once by Phase
```

## §2 Time

* Clock resolution: **96 ticks per quarter note**; a whole note is 384 ticks [DOC].
* Tempo is in quarter notes per minute; all voices share it [DOC].
* **Time Base** per voice: `numerator | denominator`. Base pulse = `384 / denominator`
  ticks, multiplied by the numerator [DOC]. Denominators: 1–9, 11, 12, 13, 15, 16, 24 and
  `sa` (step advance) [DOC]. Numerator 1–99 [DOC S2]. Several values are not whole ticks
  (5 → 76.8, 13 → 29.54…) [DOC: table]. emmm keeps fractional ticks exactly (floating-point
  tick time) [INF — the original presumably accumulated integer ticks with some
  error-diffusion; not audible at musical tempi].
* **Phase**: per-voice initial delay, 0–199 ticks, applied after Start or Sync [DOC].
* The Time Base, Output Length and Phase are stored *in the Pattern Group* with the pattern
  [DOC].

## §3 Patterns and Pattern Groups

* A Pattern is an ordered list of **steps**; a step is a set of MIDI pitches (one = note,
  several = chord, none = rest) [DOC]. Max 999 steps [DOC].
* **Output Length** = how many steps (from the start) the Voice actually plays; ≤ number of
  steps [DOC]. 0 = permanently silent [DOC]. Changing it with the modifier key adds rests at
  the end or deletes steps [DOC].
* Each Pattern also keeps a **scrambled list**: a random permutation of its steps, made when
  the pattern is recorded/edited, and regenerated by *ReScramble* [DOC]. *Don't Scramble
  Rests* keeps rests at their original indices in the scrambled list [DOC; S2 describes the
  "third list" of non-rest locations].
* **Pattern Group** is itself a Variable with six Positions `a`–`f`; each holds four
  Patterns plus their Output Length / Time Base / Phase / record modes [DOC]. Selecting a
  Pattern Group Position performs a **Sync** unless the modifier is held [DOC].

## §4 The event (note-playing) routine

When a voice's countdown reaches zero, M computes one **event**. emmm does, in this order
(order of random draws is an emmm detail, see §13):

1. **Rhythm**: read the next step of the voice's Rhythm cycle → a level 0–4 (random within
   the step's range) → global Rhythm Value table → multiplier. Interval to the next event
   = time-base ticks × multiplier [DOC: ch. 7 worked example 24 × 1, 24 × 0.5].
2. **Legato**: next step of the Legato cycle → level → global Legato Value table → percent.
3. **Accent**: next step of the Accent cycle → level 0–4 [DOC].
4. **Pitch**: choose the scheme (Original / Cyclic Random / Utterly Random) using the
   voice's Note Order percentages; read the step [DOC]:
   * Original → `steps[position]`
   * Cyclic Random → `steps[scrambled[position]]`
   * Utterly Random → `steps[random(0..outputLength-1)]`
   `position` then advances and wraps at Output Length [INF: it is a single counter shared
   by both lists; the manual describes Original vs Cyclic as reading "the original order" or
   "the scrambled copy"].
   With Output Length shorter than the pattern, a scrambled index may point beyond the
   output length; emmm then folds it (`index mod outputLength`) [UNK].
5. **Is the note played?** It is *not* played if the voice is muted (Play-Enable off), the
   pattern is a rest, the accent level is 0 [DOC S2 Fig.10, S1 "0 means … will not be
   heard"], or a Note Density coin-flip fails [DOC]. Skipped notes still consume the step and
   all three cycle steps — density produces rests, it does not slide the melody [INF from
   "about 50 percent of the Voice's notes … skipped"; S2 Fig. 10].
6. **Transposition**: semitone offset of the active Transposition Position, plus Keyboard
   Transpose (§9) [DOC].
7. **Velocity**: see §6.
8. **Orchestration**: the step is sent on every Output Channel enabled for this voice in the
   active Orchestration Position [DOC].
9. **Duration**: note-off at `interval × legato% / 100` after the note-on (may exceed 100%,
   up to the 400% example, so notes overlap) [DOC].

All cyclic variables advance **once per event**, including rests and skipped notes; the
Rhythm cycle therefore paces the Legato and Accent cycles [DOC: "the Legato Cycle … tracks
the rhythm"].

## §5 Cyclic Variables (Rhythm, Legato, Accent)

* A cycle has 1–16 steps; each step holds a single level or a contiguous **range** of levels
  0–4 from which one is picked at random each time [DOC].
* Each voice has its own cycle (own length) within each Position [DOC].
* There is **one global table** of five Rhythm Values and one of five Legato Values shared
  by every Position and voice [DOC]. Levels need not be ascending; duplicate values weight
  the randomness [DOC].
* Defaults: Legato `4=100 3=75 2=50 1=25 0=6` [DOC]. Rhythm `0=0.5 1=1` [DOC]; `2=2 3=3 4=4`
  [INF from manual screenshots].
* The cycle counter belongs to the voice and the variable, not the Position; when the active
  Position changes, the counter continues and wraps to the new length [UNK].
* The first step of the active Position's miniature blinks when the cycle restarts (not for
  one-step cycles) [DOC].

## §6 Velocity Range and Accent

* Velocity Range: per voice a low/high MIDI velocity [DOC].
* Accent levels 1–4 select "quarters" of the range [DOC]. emmm maps level `k` to
  `low + (high − low) × (k − 1) / 3`, so level 1 = low ("unaccented") and level 4 = high
  ("accented") [UNK — alternative `k/4` reading is one constant away:
  `ACCENT_MAPPING` in `src/engine/constants.ts`].
* A single-value range gives one dynamic regardless of accents [DOC].
* Continuous conducting adds a voice-wide offset (§10).

## §7 Note Density

Per-voice probability (0–100 %) that a note sounds [DOC]. 0 % → never plays [DOC].

## §8 Time Distortion

* Per voice, per Position: a monotonic breakpoint map from **real time** (x) to **clock
  time** (y) over a **length** = `count × note value` [DOC]. Default is the diagonal
  (no effect) [DOC]. The map repeats every length [DOC].
* Where the curve is steep, clock time runs fast and events crowd together [DOC example].
* emmm implementation: the voice's event times are computed in its own clock time; a clock
  time `c` is played at real time `floor(c/L)·L + f⁻¹(c mod L)` [INF; S2 implements the same
  thing with a per-tick "ticks to simulate" table].
* The period is measured from the voice's last Sync [INF].

## §9 MIDI input per voice (Patterns window)

Columns per voice [DOC]:

* **Src** — M Input Channel 1–16 or All.
* **Use** — Picture Matrix: `–` disable, `R` record, `♯♭` Keyboard Transpose,
  `C` Input Control System, Echo Map enable.
* **Play-Enable** (speaker), **Echo-Thru-Orchestration** (check mark),
  **Mouse Advance** (diamond).
* **Select** box with three record-mode icons: chord mode (Single / Chord / Build),
  insertion mode (Insert / Replace / Overdub), Drum Machine on/off.
* Output Length, Time Base, Phase.

Keyboard Transpose: incoming note − C3 (MIDI 60) = transposition; *Second Order Transpose*
adds it to the Transposition Variable instead of replacing it [DOC]. M calls MIDI 60 "C3"
[DOC] and emmm keeps that naming.

Recording [DOC]: notes are written at the Pattern Editor's MIDI Edit Counter, within the
MIDI Edit Range. Single Note splits chords into separate steps; Chord mode groups
near-simultaneous notes [chord window: UNK, emmm uses 40 ms]; Build mode accumulates
everything played while at least one key is held into one step, and re-playing a note that is
already in the building chord removes it; releasing all keys advances. Insert / Replace /
Overdub decide whether a new step is inserted, the current one replaced or added to. Drum
Machine mode makes the Edit Counter follow the playing position while running. *Sustain
Enters Rests* option: sustain pedal down records a rest.

## §10 Conducting

* Each conductable control has a **Conducting Arrow**: enabled/disabled plus a direction
  (→ ← ↑ ↓) [DOC]. Conductable: all eleven Variables, Tempo, Snapshots (first six) [DOC].
* The Conducting Grid is divided into six units on each axis; the Baton's position along the
  arrow's axis selects Position 1…6 [DOC S2 Fig. 6].
* Tempo is the exception: continuous within the Tempo Range Bar [DOC].
* **Continuous conducting** (Velocity Range and Legato only, per-voice enable "bricks"):
  Velocity adds an offset that runs from nearly silent to maximum; Legato multiplies the
  legato percentage from ×4 at one end to ×¼ at the other [DOC]. emmm: velocity offset
  `(2t − 1) × 127`, legato multiplier `4^(2t − 1)` where `t` ∈ [0,1] runs along the arrow
  [INF]. Cancelled by: removing the brick, choosing a Position by hand, disabling
  conducting, modifier-click in the grid [DOC].
* **Automatic Conducting** (Robot): at a rate from whole note to eighth note the Baton jumps
  by a random amount bounded by the horizontal / vertical jump ranges; it may not move [DOC].
* MIDI Conduct: two controller numbers move the Baton [DOC].

## §11 Tempo, transport

* Tempo Range Bar: drag draws a range, tempo is set to its midpoint; click sets a single
  value; Tempo Numerical adjusts within the range [DOC].
* **Start** (Space) plays all voices from the beginning; pressing Start while playing is a
  Sync [DOC]. **Stop** (Return) turns sounding notes off [DOC]. **Pause** (Tab) freezes
  everything *without* releasing notes — "organ sounds sustain indefinitely" — and resumes
  where it left off [DOC]. **Sync** resets every voice to its first step and first cycle step
  (quantized to the Snapshot quantization) [DOC].
* emmm keys: **Space is Play / Pause** (stopped → Start, playing → Pause, paused →
  continue), a deliberate emmm change; M's Start-while-playing Sync is **⇧Space**. Return
  and Tab are as in M. The Start *button* keeps M's behaviour (Start; while playing, Sync).
* Metronome (Options ▸ Use Metronome) clicks at the Sync Ratio note value [DOC].
* Send Clock: MIDI clock at 24 ppq × sync ratio [DOC].

## §12 Snapshots and Slideshows

* **Hold/Do** (Backspace): click → it blinks; every control then clicked blinks instead of
  changing; Hold/Do again performs them all at once; clicking a Snapshot slot instead stores
  them [DOC].
* 26 Snapshots A–Z (letter keys) [DOC]. A Snapshot stores *which Position* each included
  Variable is on (not the Position's contents), conducting arrows, the per-voice Patterns
  window settings (Src, Play-Enable, Echo, Mouse Advance, Output Length, Time Base, Phase),
  Sync, and the Sequence enable [DOC].
* **Blink Everything** (globe) selects every storable control [DOC]. **Edit Snapshot**
  (pencil) loads the current snapshot's items as blinking [DOC]. **Restore From Snapshot**
  undoes the most recent snapshot [DOC]. Capital letter / shift-click forces a Sync [DOC].
* A Snapshot does **not** store Position contents, Pattern notes, the tempo value, options
  or MIDI settings [DOC for contents; INF for the rest — they are not in the documented list].
* **Quantization** (wave = none, or a note value) delays Snapshot execution, Sync,
  Slideshow start and shift-clicked Position changes to the next multiple counted from Start
  [DOC]. Restore From Snapshot is quantized too [DOC].
* Conducting Snapshots (first six, A–F) is quantized and successive ones are queued a quantum
  apart in the order dragged [DOC S1 ch.9] — **emmm deviates** (executes at once unless
  Shift is held; no queue): U23.
* emmm explanation aids (UI only): each Snapshot box's tip lists its contents; a status line
  in the Snap window; a Snapshot waiting for quantization blinks. Research notes: RESEARCH.md
  "Snapshots".
* 9 **Slideshows** record Snapshot executions and quantized Position changes with their
  times; play, stop (0), pause, loop (\\) [DOC]. *Slideshow Record Wait*: timing starts at the
  first recorded event [DOC].

## §13 Randomness

M's randomness is a pseudo-random generator [DOC S2: precomputed cyclic tables]. emmm uses a
seeded PRNG (sfc32) per voice plus separate streams for scrambling and the Robot
Conductor. Pressing **Start** from the stopped state re-seeds all streams from the session
seed, so the same file + seed + gestures reproduce the same output. This is an emmm
infrastructure improvement, not an M feature.

## §14 Input Control System (MIDI keyboard remote)

Enabled by `C` in any voice's Use column. White keys are one-step controls; black keys are
"code" keys that wait for one white "value" key [DOC]. Value numbering: C1 = 0 (also "A"),
D1 = 1 ("B"), … one per white key up to G4 = 25 ("Z") [DOC S1 + S2 Fig. 11]. Full table in
`src/engine/inputControl.ts`. M names MIDI 60 "C3", so C1 = MIDI 36.

## §15 Pattern Editor and Pattern menu

Pattern Editor: piano-roll-like step grid (pitch vertical, step horizontal), click adds/removes
pitches, clicking past the end pads with rests, tools Selector / Eraser / Plunger (insert) /
Scissors (delete), View 1–4, MIDI Edit Counter and Range [DOC].
Pattern menu (operate on selected patterns or region) [DOC]: Transpose ± half step / octave,
ReScramble, Original→Scrambled, Swap Scrambled and Original, Rotate Forward (first becomes
last), Rotate Backward, Reverse, Double / Triple with Rests, Eliminate Chords, Eliminate Rests.
Edit menu: Cut, Copy, Paste, Clear, Paste Notes, Change to Rests, Fill With Rests, Paste at
End / Insert Paste, Erase Snapshot.

## §16 MIDI output configuration

Sixteen **M Output Channels**, each mapped to a device + MIDI channel (Midi Assignment) [DOC];
sixteen M Input Channels likewise. Sound Choice program numbers display 1–128 or 0–127 per
channel [DOC]. Stop/Cmd-period: All Notes Off on the channels of the current orchestration
[DOC]. Panic: note-off for every note [DOC]. Latency setting in ms [DOC].

emmm calls the window **MIDI Settings** (File ▸ MIDI Settings…, ⌥M): M's Midi Assignment plus
MIDI clock — Send Sync (the device for Options ▸ Send Clock, with the same switch) and clock
**input** (follow tempo, optionally Start / Stop / Continue, choice of input, status). M 2.7's
External Clock is "no longer available" [DOC]; emmm's clock input is an emmm addition, not
part of Extended (until document format 4 it was, and needed Extended on). See U25.

## §17 Movies and MIDI Files

Movie button captures all output during a performance; *Save Movie As Midi File* writes it
[DOC]. A Movie is a timed record of MIDI *output* (not of gestures — those are Slideshows);
armed before Start, un-highlighted by Stop; held in memory with an event limit; the File menu
item is enabled only once a Movie exists; default file name "M Movie" [DOC]. Unknowns: U24.
Research notes: RESEARCH.md "Movies". MIDI Files can be imported into the current Pattern Group (per-pattern channel
selection, chord method, rests none/dur, quantization) or as a play-along Sequence [DOC].

Sequence details [emmm choices, see U21]: a Sequence plays once from Start (and restarts on
Sync when *Sync Restarts Sequence* is on); MIDI channel *n* in the file plays on M Output
Channel *n*; its timing is in beats, so it follows M's tempo. Sequence Play-Enable is a mute:
the Sequence keeps running silently [DOC]. A Snapshot can include the Sequence enable [DOC].

## §18 Interface conventions

* **Numerical** [DOC S1 ch.2, S2]: press in the top half → +1 (auto-repeat while held),
  bottom half → −1; drag vertically outside the box → slider gesture with the cursor hidden;
  Shift-click → copy the last numerical value set [DOC Appendix A]. Alt with Output Length →
  structural change applied on release [DOC].
* **Range bar** [DOC]: drag draws a range; a click sets a single value; Tempo's midpoint
  becomes the tempo [DOC].
* **Choice bar / Positions** [DOC]: click selects; double-click opens the edit window; drag
  onto another Position swaps; Option(Alt)-drag copies; Shift-click quantizes; during Hold/Do
  clicks are collected (blinking) instead of performed.
* **Conducting Arrow** [DOC]: click toggles; press-and-hold rotates through the four
  directions; drag around it to point it; Velocity Range and Legato arrows open into four
  per-voice arrows with enable "bricks" for continuous conducting.
* **Picture Matrix** [DOC]: press, slide to an icon, release.
* **Edit windows** [DOC]: close triangle top-left; six-box Position selector in the title bar
  (click = edit that Position; Option-click = also make it active; Shift-Option = quantized;
  pull down = mark *). Voice numbers 1–4 drag onto each other to swap (Option: copy).
* **Windows** [DOC]: drag by the title; Cmd-click brings to front without acting; edit windows
  open with zoom rects unless *No Zoom Rects*.
* **Windows menu** [DOC S1 ch.21]: *Close Edit Windows* closes every open edit window; the
  other commands bring the named window to the front ("if no windows are on top of each
  other, nothing will appear to have happened"); the Conducting window heads the list, and the
  list changes as edit windows open and close. Cmd-Number brings a main window forward and
  Cmd-Option-Number sends it back [DOC] — not implemented in emmm, because browsers reserve
  Cmd-1…9 for switching tabs. emmm additions: the brought-forward window's title flashes (so
  the command is visible when nothing covered it), and the Cyclic Editor, Pattern Editor and
  Monitor are always listed, opening them if closed.
* **Blinking** [DOC]: Hold/Do pending items blink; the first step of a restarting cycle blinks
  in the active miniature (not one-step cycles; *No Cyclic Blinking*); Pattern Group bricks flash
  when a pattern starts over.
* **Snapshot pictures** [DOC description]: a stored Snapshot is shown as its letter "posing in
  the sun"; the current one has a black mark in its sun.
